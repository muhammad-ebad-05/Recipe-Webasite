# 🍳 Delicious Recipes Website

A simple, well-structured, and styled **Recipe Webpage** built using pure **HTML5** and **CSS3**. This project features popular traditional and fast-food dishes along with their ingredients and step-by-step cooking instructions.

---

## 🍲 Recipes Included

* **Chicken Karahi:** Authentic Pakistani chicken stir-fry cooked with tomatoes, spices, and ginger.
* **Beef Pulao:** A rich, fragrant rice dish cooked in spiced beef broth (Yakhni).
* **Traditional Pakistani Kheer:** Slow-cooked rice pudding infused with green cardamom, nuts, and kewra water.
* **Crispy Zinger Burger:** Double-crusted, crispy fried chicken burger loaded with lettuce and mayo.

---

## 🌟 Features

* **Semantic Layout:** Built using organized headings, lists (`<ul>`), image tags, and horizontal rules (`<hr>`).
* **Clean Styling:** Formatted with custom background colors and text alignment.
* **Visual Appeal:** Aligned images alongside step-by-step cooking instructions and styled bullet points.

---

## 🛠️ Built With

* **HTML5:** Semantic markup, structure, and text alignment.
* **CSS3:** Custom background styling and element coloring.
