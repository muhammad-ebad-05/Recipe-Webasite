# 🍲 Make Delicious Food - Recipe Website

A simple, structured, and static recipe website built using **pure HTML5**. It provides step-by-step cooking instructions and ingredient lists for popular Pakistani dishes and fast-food items.

---

## 🍽️ Featured Recipes

1. **Chicken Karahi** – A classic Pakistani dish cooked with tomatoes, green chilies, yogurt, and freshly ground spices[cite: 1].
2. **Beef Pulao** – A flavorful and fragrant rice dish made with tender beef stock (Yakhni) and whole aromatic spices[cite: 1].
3. **Traditional Pakistani Kheer** – A rich, slow-cooked rice pudding infused with green cardamom, kewra water, and mixed nuts[cite: 1].
4. **Crispy Zinger Burger** – A crunchy fast-food style chicken burger with buttermilk marination, iceberg lettuce, and mayonnaise[cite: 1].

---

## ✨ Features

- 📄 **Pure HTML Structure:** Built entirely using semantic HTML elements without external CSS or JavaScript dependencies[cite: 1].
- 🖼️ **Visual Content:** Embedded high-quality dish photographs accompanying each recipe[cite: 1].
- 📝 **Structured Sections:** Uses ordered lists, bullet points, and headers for clear ingredients and cooking steps[cite: 1].
